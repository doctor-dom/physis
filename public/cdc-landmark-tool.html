CDC chart landmark tool

Click the chart to record pixel anchors. Export JSON, save to data/cdc/landmarks/, then run npm run apply:cdc-landmarks to regenerate plotter coordinates. Coordinates are in native PNG pixels (top-left origin).

    Tip: zoom in before clicking. Place points at grid intersections (stature/weight lines cross age columns). For age landmarks, click the vertical grid line under the printed age label. Hover any anchor dot to see the logged JSON and x-order integrity.
