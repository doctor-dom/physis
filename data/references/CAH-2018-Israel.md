# CAH screening — Israeli newborn screening algorithm (Table 2)

Table 2 from Pode-Shakked et al. describes the **operational Israeli newborn screening algorithm** for 17-OHP, including repeat-request cutoffs and criteria for interpreting recall samples.

## Citation

Pode-Shakked N, Blau A, Pode-Shakked B, et al. Combined gestational age- and birth weight-adjusted cutoffs for newborn screening of congenital adrenal hyperplasia. *J Clin Endocrinol Metab*. 2019;104(8):3172-3180. doi:[10.1210/jc.2018-02468](https://doi.org/10.1210/jc.2018-02468) (Table 2).

## Requirements

- **Birth weight** (required)
- **Gestational age** (optional — if omitted, uses the “unknown GA” row for the birth-weight stratum)

Gestational age is **rounded up** to the next whole week (e.g. 36 weeks + 1 day → 37 weeks).

## Interpretation (initial sample)

| Birth weight | Action |
| --- | --- |
| ≤2500 g, 17-OHP ≥ repeat-request cutoff | Request repeat sample |
| >2500 g, 17-OHP ≥ 90 nmol/L | Refer for CAH evaluation (first sample) |
| >2500 g, 17-OHP ≥ repeat cutoff but < 90 | Request repeat sample |
| Below repeat cutoff | No repeat indicated by this algorithm |

## Repeat sample criteria

| Birth weight | Recall sample normal if |
| --- | --- |
| ≤2500 g | >30% reduction from initial sample |
| >2500 g | Repeat 17-OHP **<** repeat cutoff (70 or 35 nmol/L by GA row), independent of initial value |

For infants **>2500 g**, the first-sample referral threshold (**≥ 90 nmol/L**) applies regardless of repeat-cutoff logic.
